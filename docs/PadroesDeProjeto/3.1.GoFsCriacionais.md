# 3.1. Módulo Padrões de Projeto GoFs Criacionais

## 1. Introdução

Conforme apresentado no livro **Design Patterns: Elements of Reusable Object-Oriented Software**, os **Padrões de Projeto Criacionais**, definidos pela **Gang of Four (GoF)**, têm como objetivo abstrair o processo de criação de objetos, tornando o sistema independente de como seus objetos são instanciados, compostos e representados.
Esses padrões encapsulam o conhecimento sobre quais classes concretas são utilizadas e como suas instâncias são criadas, expondo apenas as interfaces definidas por classes abstratas.

Ao ocultar detalhes de criação, os padrões criacionais oferecem **flexibilidade para decidir o que é criado, quem cria, como cria e quando cria**, permitindo configurar sistemas com objetos que podem variar amplamente em estrutura e comportamento, tanto em tempo de compilação quanto em tempo de execução.

Além disso, esses padrões podem ser alternativos ou complementares entre si. Em alguns cenários, diferentes padrões podem resolver o mesmo problema, enquanto em outros podem atuar juntos para construir objetos mais complexos ([GAMMA et al., 1995](https://www.javier8a.com/itc/bd1/articulo.pdf)).

## 2. Metodologia

Embora os Padrões de Projeto Criacionais incluam **Factory Method, Abstract Factory, Builder, Prototype, Singleton, Multiton e Object Pool**, conforme apresentado pela professora Milene Serrano **(SERRANO, 2026)**, considerando a etapa de [Modelagem de Software](https://unbarqdsw2026-1-turma01.github.io/2026.1-T01-_G4_FCTE_Hoje_Entrega_02/#/), bem como a redução de escopo e a adequação ao projeto FCTE Hoje, foram aplicados os seguintes padrões na fase atual:


- [Builder](./3.1.1.Builder.md): Permite criar objetos complexos passo a passo, separando a construção da representação final.
- [Factory Method](./3.1.2.Factory.md): Define uma interface para criação de objetos, permitindo que subclasses decidam qual classe concreta instanciar 
- [Singleton](./3.1.3.Singleton.md): Garante que apenas uma instância de uma classe exista durante toda a execução do sistema, fornecendo um ponto global de acesso.
